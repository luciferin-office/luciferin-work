# 루시페린 워크 (윈도우 PC 프로그램)

루시페린 오피스(crm.luciferin.kr)를 그대로 담는 프로그램입니다.
- 켜면 대화 창(#chatapp)이 열리고, 왼쪽 업무 단추를 누르면 오피스 창이 따로 열립니다.
- 창을 닫아도 꺼지지 않고 시계 옆 아이콘으로 남습니다. (끝내기: 아이콘 오른쪽 클릭 → 끝내기)
- 안 읽은 대화 수가 작업표시줄 아이콘에 뜨고, 새 글이 오면 아이콘이 깜빡이며 윈도우 알림이 뜹니다.
- 처음 설치하면 컴퓨터를 켤 때 자동 실행이 켜집니다. (아이콘 메뉴에서 끌 수 있음)
- 화면 내용은 오피스를 배포하면 저절로 바뀝니다. 프로그램 자체 업데이트는 crm.luciferin.kr/desktop/ 에 새 설치 파일을 올리면 저절로 받습니다.

## 설치 파일 만들기 (둘 중 하나)
1. 윈도우 PC: Node.js LTS 설치 → 이 폴더의 build-windows.bat 실행 → dist 폴더에 설치 파일.
2. GitHub: 이 폴더를 저장소로 올리면 Actions 가 윈도우 설치 파일을 만들어 줍니다.
